# side-comment

わんコメ用のコメント表示テンプレートです。画面の端に縦長に置いて、アイコンとコメントを表示します。

設定ページ：https://esusan.github.io/onecomme-side-comment/

## 特徴

- アイコンと、コメントの上に小さく名前を表示します。名前は消すこともできます
- 等幅フォント（UDEV Gothicを同梱）で、行の端がそろいます
- 文字の大きさ・1行の文字数・行数・色・背景の濃さ・左右どちらに寄せるかを設定ページで選び、URLで指定します
- 前の配信のコメントや、本文のないスパチャは表示しません

## 導入方法

1. [設定ページ](https://esusan.github.io/onecomme-side-comment/)の「テンプレートをダウンロード」でzipをダウンロードして展開します
2. `side-comment` フォルダを `%APPDATA%\onecomme\templates\custom\` に入れます
3. わんコメのテンプレート画面（右上の「…」メニュー →「テンプレート」）に side-comment が出ていればOKです。出ていなければ、わんコメを起動し直してください
4. 設定ページで見た目を決めてURLをコピーし、OBSのブラウザソース（「ローカルファイル」はオフ）に貼ります。見た目の設定はURLの末尾に入っています
5. ブラウザソースの幅を設定ページに出る数字に合わせます。文字の大きさ・1行の文字数・アイコンを変えたときは、幅も合わせ直してください
6. 配信の前に、わんコメのコメントテスター（右上の「…」メニュー →「コメントテスター」）でコメントを流して、表示を確かめておくのがおすすめです

見た目を変えるときは、URLを貼り直すだけで大丈夫です。ダウンロードしたzipの `config.js` にもその時の設定が入るため、わんコメからドラッグして入れた場合（ローカルファイル指定でURLの設定が付きません）はその設定で表示されます。URLパラメータがあるときはそちらが優先されます。

## URLパラメータ

| 名前 | 既定 | 内容 |
| --- | --- | --- |
| size | 24 | 文字の大きさ(px) |
| cols | 15 | 1行の文字数（全角） |
| lines | 3 | 最大の行数。超えた分は省略します |
| side | left | 寄せる側（left / right） |
| font | udev | udev / bizud / sans |
| accent | ffffff | ラインの色（#なしの16進） |
| bg | 65 | 背景の黒の濃さ(0〜100) |
| icon | 1 | 0でアイコンを表示しません |
| name | 1 | コメントの上に名前を1行表示します。0で表示しません |
| namescale | 60 | 名前の大きさ（コメントの文字に対する%） |
| namecolor | white | 名前の色。white（白）/ accent（ラインと同じ色） |
| life | 0 | 消すまでの秒数（0は時間では消しません） |
| max | 12 | 同時に表示する件数 |
| demo | なし | 1でダミーコメントを流します（all で全部一度に表示） |

## コメントが出ないとき

- 赤い枠で「コメントを受け取れません」と表示されるときは、side-comment フォルダが `%APPDATA%\onecomme\templates\custom\` の外にあります
- 見た目が変わらないときは、ブラウザソースが「ローカルファイル」指定になっていないか確認してください。オフにしてURLを貼ってください
- わんコメの配信枠の「書き出し」がオフだと、その枠のコメントはテンプレートに送られません。コメントテスターでは出るのに配信のコメントが出ないときは、まずここを確認してください
- わんコメは限定公開の配信のコメントを取得できません。テストは公開の配信で行ってください
